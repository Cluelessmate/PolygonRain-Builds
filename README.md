# Polygon Rain — Public Builds

**Polygon Rain** is a PS1-style, Risk of Rain 2–inspired roguelite shooter set in a post-apocalyptic wasteland. Pilot a jetpack mech, stack items, and survive as the difficulty climbs.

## Download

Grab the latest build from the **[Releases](https://github.com/Cluelessmate/PolygonRain-Builds/releases/latest)** page.

1. Download `PolygonRain-vX.Y.Z-windows.zip`
2. Unzip it anywhere
3. Run `PolygonRain.exe`

Windows 10/11, 64-bit. If SmartScreen warns about an unknown publisher, click **More info → Run anyway**.

## Controls

| Key | Action |
|---|---|
| WASD | Move |
| Space | Jump / hold to jetpack-hover |
| Ctrl | Sprint |
| LMB / RMB | Primary weapon / piercing shot |
| R | Grenade |
| Shift | Dash |
| Q | Ultimate |
| E | Interact |
| Tab | Inventory |
| Esc | Pause / settings |

## About this repo

This repository only hosts playable builds. Each release includes the changelog for that version.
